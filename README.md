# Nassau Candy Shipping Route Efficiency Analysis

This project analyzes factory-to-customer shipping efficiency for Nassau Candy Distributor.

## Objectives
- Identify efficient and inefficient shipping routes
- Detect geographic bottlenecks
- Compare ship mode performance
- Provide logistics intelligence dashboard

## Tools Used
- Python (Pandas, NumPy)
- Google Colab
- Streamlit
- Matplotlib & Seaborn

## Files
- Nassau_Shipping_Route_Efficiency_Analysis.ipynb → Data analysis notebook  
- app.py → Streamlit dashboard  
- nassau_clean_data.csv → Cleaned dataset  
- nassau_route_kpis.csv → Route KPIs  
- Nassau_Final_Report.pdf → Project report  
- Nassau_Project_Presentation_Final.pptx → Presentation  

## How to Run Dashboard
```bash
pip install streamlit pandas
